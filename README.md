# MLB International Amateur Market

A census of MLB international amateur free agent signings, 2009–2021.

The site is a single self-contained page: `index.html`. Every figure on it is
generated from the census build, and the charts run on precomputed aggregates —
this repository holds the rendered page only, not the data pipeline behind it.

Built by [Elliot Wolf](https://github.com/elliot-wolf).
